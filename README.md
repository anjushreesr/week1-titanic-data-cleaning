# Titanic Dataset Cleaning and Preprocessing

This project focuses on cleaning and preprocessing the Titanic passenger dataset using Python. It handles missing values, encodes categorical data, and visualizes the age distribution of passengers.

## Objectives

- Load and explore the Titanic dataset using Pandas.
- Identify and handle missing values.
- Encode categorical columns using LabelEncoder and OneHotEncoder.
- Visualize passenger age distribution using Matplotlib.
- Save the cleaned dataset as a CSV file.

 ## Technologies Used
 
 - Python
- Pandas
- Matplotlib
- Scikit-learn

## Project Files

- `week1_assignment.py` — Python source code for data cleaning and preprocessing.
- `titanic_cleaned.csv` — The cleaned Titanic dataset.
- `age_distribution.png` — Histogram showing the age distribution of passengers.

## Outcome

The project successfully cleans and preprocesses the Titanic dataset by handling missing values and encoding categorical features. It also generates an age distribution histogram and exports the processed data to a new CSV file.
